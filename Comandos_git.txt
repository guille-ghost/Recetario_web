Para suibir modificaciones
git add .
git commit -m "Descripsion de la version"
git push

si sale un fatal

git push --set-upstream origin main

Si realizas nuevos cambios:

git add .
git commit -m "Nuevos cambios"
git push origin main

y en cualquier otra maquina

git pull origin main
